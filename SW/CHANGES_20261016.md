# 2026-10-16 실물 도킹·매니퓰레이션 변경 정리

기준 브랜치는 `fix/g2-self-mask`, 변경 전 커밋은 `cd59540`이다. 이 변경에는 기존 로컬의 충돌 보호·Nav2·관제 UI 작업과 Phase 0~3 후속 개발을 함께 포함한다. 개인 `config.json`, 설치 결과물, 로그, 로컬 백업은 커밋하지 않는다.

## Closed approach

- 웹 브리지와 별도 프로세스에서 20Hz 목표로 도킹을 제어한다. 웹 상태 전달은 크기를 제한하고, 부모 heartbeat 유실·종료 시 제어를 중단한다.
- 접근 중 MID-360 `fit_edge`로 선택한 책상 가장자리를 갱신한다. 사각 구간에서는 마지막 실측 경계와 odometry를 사용한다.
- 10cm 조기 성공을 제거했다. 완료에는 전후 1.5cm·좌우 2cm·heading 2도 이내, 책상 간격 0~3cm와 실제 정지가 필요하다.
- 책상 법선에 수직으로 진입하고 물체를 팔의 선호 좌표 `(0.392, -0.078)m` 쪽에 정렬한다. 이것은 선호 오프셋이며 사전 계산된 IRM은 아니다.
- 복구는 최대 15cm 직선 후진이다. 정밀 도킹 중 일반 FrontRetreat가 개입하지 않는다.
- 도킹 완료 시 `/detection/dock/surface`에 실측 odom polygon을 전달한다. 새 접근·취소·오류는 이전 인계를 무효화한다.

## 매니퓰레이션

- `/manipulation/reset`은 신선하고 오류 없는 정지 피드백을 확인한 뒤 trip을 해제한다. 정상 대기 정지는 불필요한 trip을 남기지 않는다.
- 그리퍼는 목표 폭 외에 실제 닫힘 이동·정체·effort 크기·서로 다른 새 피드백을 사용해 접촉 파지를 인정한다. 실제 성공 기록의 음수 effort도 크기로 처리한다.
- 작업의 approach 시각과 맞는 테이블을 잠금 lease 시각의 작업 좌표계로 변환해 고정한다. 회전된 경계 그대로 MoveIt 메쉬와 지지면 검사에 사용한다.
- 궤적의 미분값을 보존하는 연속 스플라인을 계획 검사와 Piper 실행에 공유한다. 다항식 극값에서 위치·속도·가속도를 검사하고 실제 보간 경로도 이산 충돌 검사한다. 스트리밍 목표는 100Hz다.
- 구형·원통형 물체에 0~150도 yaw 후보를 계획한다. TCP 편심을 반영해 grip center를 유지하며 바나나는 실측 주축을 따른다.
- 기존 설치 runtime에만 있던 관제센터 입력 어댑터, integrated launch, readiness, 작업 중복 방지·잠금 유지, 손목 시각 동기화와 주변 장애물 처리도 저장소에 통합했다.

## 인지·통신·관제

- calibrated_streams는 RGB를 중계하지 않고 CameraInfo만 발행한다. Head/Wrist RGB 소비자는 RealSense 원본 토픽을 직접 사용한다.
- Head LiDAR 투영 전에 보정값별 frustum 필터를 적용한다. 기존 왜곡·광선 역투영 검사는 유지한다.
- 사용자 결정에 따라 손목은 범용 SAM 2.1을 유지한다. YOLO 탐지는 기존 TensorRT 엔진을 사용하고 대상 후보가 없으면 SAM을 실행하지 않는다.
- 손목 지연의 YOLO/마스크·depth 시간, 촬영 후 age, p50/p95와 50ms 목표 충족 여부를 발행한다. 실제 50ms 달성이나 100Hz 주기 정확도를 측정했다는 의미는 아니다.
- 64MiB FastDDS 프로필은 collision cloud/guard 실행기에 한정한다.
- 누적 로컬 변경의 공유 3D collision scene, Nav2 scene/route layer와 guarded backup, 실측 model joint 입력, 베이스 잠금 adapter, Detection/Manipulation UI·이벤트·계측을 포함한다.

## 설치와 실행

`bash SW/robot/build-collision.sh`는 새 C++ 릴리스를 설치하고 current를 전환한다. `bash SW/manipulation/build-runtime.sh`는 소스 스냅샷으로 새 매니퓰레이션 릴리스를 설치하고 성공 후 current를 전환한다. 이전 릴리스는 보존한다.

관제센터는 `bash SW/control_center/jetson-center.sh start --detection`으로 최신 저장소 Python 코드와 설치 overlay를 사용한다. Head/센서·독립 도킹 제어를 시작하지만, 지도 위치추정·Nav2 준비와 물체 이동 명령은 UI에서 수행한다. 팔은 별도 실측 설정과 commissioning 조건이 필요하며 읽기 전용 모니터를 켜는 것만으로 움직이지 않는다.

배포 전 통합 경로의 오프라인 회귀 101개가 통과했다. 이는 모터 이동, 실물 도킹·픽앤플레이스 성공 또는 실시간 성능 달성의 증거가 아니다.

상세 계약: [Detection](control_center/DETECTION.md), [Manipulation](control_center/MANIPULATION.md), [충돌 보호](robot/collision-avoidance.md).

## 원격 manipulation 비교 및 채택

비교 기준은 로컬 `cc0cc26`과 원격 `codex/manipulation-control-center-compatible`의 `dcac378`이다. main에 양쪽 이력을 merge하며 기존 Detection/Manipulation 탭을 유지한다.

| 영역 | 채택 및 이유 |
|---|---|
| 도킹→팔 인계 | 원격의 retained Target/ApproachResult, 시작 시각 기반 세션 식별, 완료 후 이동 무효화 채택. 진행 상태보다 완료가 먼저 도착하는 인계 누락 해결 |
| 관제 UI | 원격의 인계 좌표·완료 상태 표시 채택. 팔 readiness와 구분하고 이전 작업 결과가 새 인계를 가리지 않게 함 |
| 실시간 도킹 | 로컬 유지. 원격 전체 교체 시 별도 제어 프로세스, live edge 갱신, 엄격 완료 및 후진 복구가 빠짐 |
| 팔 궤적·오류 복구 | 로컬 연속 스플라인·보간 충돌 검사·reset·최소 닫힘 이동과 정체 판정 유지. 원격은 구간마다 정지하는 보간과 stop 시 무조건 trip 방식 |
| 테이블·손목 | 로컬 동적 polygon·yaw 탐색·SAM 2.1 profile 유지. 원격의 static 28mm fixture·미지정 scene_frame을 동적 도킹 기본값에 적용하지 않음 |
| 통합 기반 | 작업 중복 방지, terminal 잠금, factory depth, hand-eye 검사는 양쪽에 이미 공통으로 포함됨 |
| 배포 도구 | 원격의 동시 편집 감지·rollback 채택. 예전 runtime 하드코딩 제거, 현재 runtime 포인터 유지, 웹 제어 의존 파일 함께 포함 |

원격 문서의 과거 실물 성공 기록은 해당 실험에만 해당한다. 이번 통합의 실물 도킹·픽앤플레이스 성공 또는 주기 성능 측정으로 간주하지 않는다.

### 관제센터 명령 오류 수정

화면의 `'Sensors' object has no attribute 'navigation_available'`는 별도 제어 프로세스의 SensorManager 대행 인터페이스 누락이었다. 부모 프로세스가 전달한 최신 Nav2 managed/publisher 상태를 조회하도록 연결했다. Nav2가 이미 실행 중이거나 시작 중이면 중복 기동을 요청하지 않으며, 목표 전송 전 lifecycle·충돌 보호 검사는 유지한다. 실제 `connect_navigation`을 호출하는 회귀 사례로 미실행·실행·시작 중·상태 갱신을 검사했다.

통합 회귀 192개와 관제 제어·도킹 수정 회귀 16개가 통과했다(중복 포함). UI 인계 렌더링 테스트도 통과했다. 이 검사는 실물 이동 성공을 의미하지 않는다.

ROS_DOMAIN_ID=187/localhost 격리 인계 검사도 통과했다. 실제 ROS 메시지로 접근→실측 정지→동일 ID 인계→늦게 연결한 웹의 과거 작업 재실행 차단→이동 시 무효화를 확인했다. 테스트는 두 웹 노드를 단일 executor에 등록해 콜백 누락을 방지하며, adapter는 완료 후 이동을 감지하면 정기 heartbeat를 기다리지 않고 상태를 즉시 발행한다. 목표·차체 속도 명령은 발행하지 않았다.
