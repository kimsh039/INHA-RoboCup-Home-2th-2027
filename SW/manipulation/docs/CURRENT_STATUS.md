최신 사용자 방향은 실제 디텍션을 받는 라이브 데모다. 임시bench 입력은 기본절차가 아니며 [LIVE_DEMO.md](LIVE_DEMO.md)를 따른다. GitHub20261012의6클래스출력ID를확인해모든규칙과mock계약에반영했다. 이전7클래스raw ID를직접전달하지않는다.

## 실제 실행 전에 남은 핵심

1. Jetson의 실제 Piper 관절/그리퍼 피드백, 관절 sign/offset, 폭 대응·접촉 판정 확인. 노트북 CAN 확인 사실과 구분한다.
2. **이미 반영한 실물 hand–eye**가 현재 카메라 장착에 해당하는지와 depth 프로필·취득시각 TF 확인. 새 보정을 처음부터 다시 하라는 뜻은 아니다. 보고된 실물 최대 위치 편차12.71mm를 기록하고 실제 파지 오차에 따라 보완한다.
3. 실제 테이블 높이/범위, 주변 장애물, 복귀 관절 자세 입력 및 MoveIt 계획 대조.
4. 디텍션만 임시로 주는 외부 입력과 실제 접근 완료·베이스 잠금 연동. 기본 패키지의 로봇 상태 검사를 가짜 값으로 대신하지 않는다.

상태 머신/진행·결과, 재관측 위치 계산, depth 품질/대상 연계, 클래스별 파지, MoveIt 계획·충돌, Piper trajectory/폭 bridge, 보정 도구와 mock 계약 검사는 작성돼 있다. 2026-10-12 단위58개를 검증했고 mock12시나리오는2026-10-11 기록이다. 실물 실행은 아직 검증하지 않았다. 설정·실제 ROS 연결의 읽기 전용 점검과 EE↔TCP 현장 확인은 [DEMO_CHECK.md](DEMO_CHECK.md)를 따른다.

## 실물 hand–eye 반영 근거

- 원본: `feature/wrist-handeye-calibration` commit `0bac1e558075600d21c6b7273f26a6858266ea0d`의 `SW/simulation/calibration/wrist_handeye/wrist_handeye_calibration.yaml`.
- `references/`에 원본 YAML 텍스트와 실물15개 측정 dataset을 보존했다. 원본 YAML의 `validation` 들여쓰기가 matrix 목록에 잘못 들어가 있어 파싱 시 그 한 줄만 정상화했다. GitHub 원본은 수정하지 않았다.

- source 결과에 기록된5개 live 검증 자세: 평균 위치 편차9.37mm, 최대12.71mm, 평균 방향0.99°, 최대1.25°. 현재 작업에서 로봇에 연결해 재검증하지 않았다.
