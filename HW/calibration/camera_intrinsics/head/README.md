# 헤드 카메라 — D435 RGB 내부 캘리브레이션 결과

RGB 카메라의 내부 파라미터와 저장 영상의 재투영 오차 결과입니다. 로봇·카메라 사이의 외부 변환이나 hand-eye 결과는 포함하지 않습니다.

## 주요 결과

- fx / fy: 605.53244 / 608.06854 px.
- cx / cy: 331.95871 / 243.32325 px.
- D (k1, k2, p1, p2, k3): [0.082175, -0.163474, -0.001177, 0.005889, 0.000000].
- 전체 재투영 RMS: **0.526316785 px**.
- 교차점 검출 성공: **43/43장**, 총 **3,010개**.
- 이미지별 RMS 중앙값: 0.352601230 px.
- 교차점 거리 95백분위: 1.024977970 px.

저장된 K/D를 고정하고 각 영상의 보드 자세만 추정한 후, 검출 픽셀과 재투영 픽셀의 차이를 계산했습니다. RMS 정의는 `sqrt(sum((u_detect-u_project)^2 + (v_detect-v_project)^2) / N)`입니다.

캘리브레이션에 사용한 영상의 사후 재투영 오차이며 ROS 원래 최적화 RMS와 구분합니다. 새 영상의 독립 검증, 로봇의 mm 오차 또는 hand-eye 정확도 검증은 아직 수행하지 않았습니다.

## 적용 범위

해당 시리얼 번호의 RGB 카메라와 영상 조건에 사용합니다. 손목 카메라나 같은 모델의 다른 장비에 그대로 적용하지 않습니다. K/D는 원본 영상, P는 보정 후 영상에 해당합니다. 해상도·크롭·리사이즈가 바뀌면 해당 영상 좌표에 맞는 내부 행렬이 필요합니다. 저장만으로 장치 또는 ROS camera_info가 자동 갱신되지는 않습니다.
