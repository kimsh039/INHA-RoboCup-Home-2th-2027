# 손목 카메라 — D435IF RGB 내부 캘리브레이션 결과

카메라의 내부 파라미터와 저장 영상의 재투영 오차 결과입니다. 로봇과 카메라 사이의 hand-eye 변환은 아직 계산하지 않았습니다.

## 측정 조건

| 항목 | 값 |
| --- | --- |
| 수행 날짜 | 2026-10-10 |
| 카메라 역할 | 손목 카메라 (`wrist`) |
| 카메라 | RealSense D435IF |
| 시리얼 번호 | 243222070076 |
| 영상 | RGB, 640×480, 15fps |
| 환경 | Ubuntu 22.04, ROS 2 Humble |
| 체커보드 | 11×8칸, 한 칸 2.5×2.5cm |
| 내부 교차점 | 10×7개, 간격 0.025m |
| 계산에 사용한 영상 | 41장 |

## 결과와 해석

- 전체 재투영 RMS: **0.577404525 px**.
- 교차점 검출 성공: **41/41장**, 총 **2,870개** 교차점.
- 저장된 K/D를 고정하고 각 영상의 보드 자세를 추정한 뒤, 검출 픽셀과 재투영 픽셀의 차이를 계산했습니다.
- RMS 정의: `sqrt(sum((u_detect-u_project)^2 + (v_detect-v_project)^2) / N)`.
- 캘리브레이션에 사용한 영상을 다시 평가한 결과이며, 새 영상에 대한 독립 검증은 아직 수행하지 않았습니다.
- ROS 원래 최적화 RMS와 구분되는 사후 재투영 오차입니다. 로봇의 mm 오차나 hand-eye 정확도를 의미하지 않습니다.

## 적용 범위

이 결과는 위 시리얼 번호의 RGB 카메라와 영상 조건에 해당합니다. 같은 모델의 다른 카메라에 그대로 적용하지 않습니다. 해상도·크롭·리사이즈가 바뀌면 해당 영상 좌표에 맞는 내부 행렬이 필요합니다.

YAML의 K/D는 원본 영상에 대한 값이며, P는 보정 후 영상의 투영 행렬입니다. 파일을 저장하는 것만으로 장치나 ROS의 camera_info가 자동 갱신되지는 않습니다.

이 폴더에는 결과 파일만 보관합니다. 원본 사진, 사진이 포함된 압축 파일, 계산 코드는 포함하지 않았습니다. 원본 영상은 재검증을 위해 별도로 보관합니다.
