## 실패 기록과 남은 불확실성

- [이전 실패](../reports/time_reset_collision_failure.json): rack_base_link–link2 충돌과 음수 simulation 경과 시간이 관찰됐습니다. 시간 역행 시 기존 궤적 적용을 중단하고 진단 JSON을 저장하도록 보강했습니다. 원인은 확정하지 않았으며 사용자 Reset 조작으로 단정하지 않습니다. 최신 성공 한 번으로 원인 해결이나 반복 성공률을 주장하지 않습니다.
- [빈 그리퍼 진단](../reports/empty_gripper_baseline_comparison.json): 물체 없이 끝까지 닫을 때 손가락 간 충돌이 기존 모델에서도 재현됐습니다. 실제 큐브 접촉 파지의 성공 여부와 구분합니다.
- 원본 상위 50개 RViz 확인은 사람이 수행하는 단계입니다. 이번 문서에서는 자동 검증 완료로 표시하지 않습니다.
- 실제 센서 노이즈·hand–eye·TCP 보정, CAN 구동, 마운트 탄성·처짐, 다른 물체와 반복 성공률은 미검증입니다.

오류 시 터미널 3의 단계 로그와 터미널 1의 물리 로그를 함께 봅니다. 새 runtime incident는 `reports/runtime_incident_latest.json`에 저장됩니다. 로그·생성 모델·venv·체크포인트는 Git에서 제외합니다.
